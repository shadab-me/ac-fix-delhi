# AC Fix Delhi - landing page (GitHub Pages)

Static landing page for AC Fix Delhi, an independent all-brands home appliance repair service in Delhi NCR. Phone: +91 94110 78560 (call + WhatsApp). Visit charge Rs 450.

## Compliance - do not remove
- Independence disclosure in the footer of index.html. Required to avoid Google Ads misrepresentation suspensions.
- No brand logos or "official/authorized service center" claims. Brand names appear only descriptively, with the disclaimer.
- Privacy policy at privacy.html (Google Ads requires it).
- No service promises (same-day, warranty, hours) are made anywhere; add them only if actually offered.

## Custom domain later
To use a custom domain: buy the domain, add a file named CNAME containing the domain (e.g. acfixdelhi.in), set the domain in Settings > Pages > Custom domain, and point the domain's DNS at GitHub Pages.

## Publishing
GitHub Pages: Settings > Pages > Deploy from branch, main, /(root). Live at https://shadab-me.github.io/<repo>/
